WUW CAM / Rust

An alternative firmware for the WUW CAM, written in no_std Rust on esp-hal. It runs on the same ESP32-S3 + OV5640 hardware as the C++ firmware, and it uses the same partition table and stored settings, so you can flash either one.

Status: phase 1 spikes

Three small test programs show whether each peripheral works in pure Rust before the full firmware is written. The library crates are tested on a regular computer. The spikes still need a real camera.

Try the host tests

cd rust/ov5640 && cargo test
cd rust/wuw-board && cargo test
cd rust/wuw-frame && cargo test

The spikes need the esp Rust toolchain (espup install). Back up the camera's flash before you flash anything:

espflash read-flash 0 0x1000000 backup-<cam>.bin
cd rust/spikes/spike-net && cargo run --release

To go back to the C++ firmware, run pio run -e wuwcam -t upload from the repo root.
